# Озвучка ElevenLabs через сервер (v5)

Динамическая озвучка любого текста дня семью клонированными голосами. Модель — **Eleven v4** (`eleven_v4`).
Ключ ElevenLabs хранится **только на сервере** в переменной окружения `ELEVENLABS_API_KEY`. В браузер, в `index.html` и в git он не попадает.

## 1. Что проверено через API (22.11.2026)

| Проверка | Результат |
|---|---|
| Модель `eleven_v4` | ✅ есть. Несуществующая модель возвращает ошибку `model_not_found`, то есть API не подменяет модель молча |
| Языки | ✅ `language_code` `ru`, `kk` и `en` модель принимает; неизвестный код (`xx`) отклоняется с `unsupported_language` |
| Happy: ru / kk / en | ✅ 4.8 / 5.1 / 4.8 с аудио. Настройки: Stability Natural (0.5), язык Auto (без `language_code`) |
| Остальные 6 голосов (ru) | ✅ Woman, Angry, Mysterious, Man, Zesty, Sad: все 200 OK, 4.0–4.6 с аудио |
| Аудиотеги эмоций | ✅ понимаются: `[whispers]` даёт ту же длину и −8.6 дБ (шёпот), а не читается вслух |
| Лимит тарифа | одновременно не больше 3 запросов (`Maximum-Concurrent-Requests: 3`) |
| Стоимость | заголовок `Character-Cost`: около 0.4–0.5 кредита за символ на v4 |

Ключ, на котором шла проверка, ограничен только правом TTS: прав `models_read`, `user_read`, `speech_to_text` и `speech_history_read` у него нет. Это хорошо для безопасности. Поэтому языки подтверждены через `language_code`, а не через список моделей. Правильность произношения слушайте ушами: файлы тестов приложены в чате.

## 3. Как это работает

```
браузер ──POST /api/tts {voice:"happy", mode:"happy", lang:"ru", text}──▶ сервер ──xi-api-key──▶ ElevenLabs
        ◀───────────────────────── audio/mpeg ──────────────────────────
```

- `GET /api/tts` — состояние сервиса: подключён ли ключ, модель, список голосов и лимиты. Ключ в ответе не возвращается.
- `POST /api/tts` — озвучка. Браузер передаёт только **имя** голоса. Voice ID, модель и аудиотеги задаёт сервер.
- Порядок выбора на сайте:
  1. сервер `/api/tts`;
  2. если сервера нет — личный ключ в ⚙ (прежний режим);
  3. если нет ни того, ни другого — голос браузера.

  При открытии файлом, на GitHub Pages и в OneCompiler сайт работает как раньше.
- Готовое аудио кэшируется в самом дне (`day.voiceAudio`), как и раньше. Повторное прослушивание бесплатно. На сервере тоже есть кэш в памяти.

## 4. Ограничение расходов

| Переменная | По умолчанию | Что ограничивает |
|---|---|---|
| `TTS_MAX_CHARS` | 2500 | символов в одном запросе (длинный текст сайт сам делит на части) |
| `TTS_MAX_TEXT_CHARS` | 6000 | символов во всей записи дня; длиннее — читает голос браузера |
| `TTS_IP_PER_MINUTE` | 10 | запросов в минуту с одного IP |
| `TTS_IP_DAILY_CREDITS` | 8000 | кредитов в сутки с одного IP |
| `TTS_DAILY_CREDITS` | 40000 | кредитов в сутки на весь сайт |
| `TTS_CONCURRENCY` | 2 | одновременных запросов к ElevenLabs (тариф допускает 3) |
| `TTS_CACHE_MB` | 32 | кэш аудио на сервере: повтор того же текста не тратит кредиты |

Сервер учитывает настоящую стоимость из заголовка `Character-Cost`. Счётчики обнуляются в полночь UTC.

> ⚠️ Счётчики живут в памяти процесса. На Vercel у каждого экземпляра функции свои счётчики, и после перезапуска они начинаются с нуля.
> Поэтому **жёсткий потолок обязательно задайте в ElevenLabs**: Developers → API Keys → ключ → *Credit limit*.

Ещё одна защита — `TTS_ALLOWED_ORIGINS`: список адресов сайта, с которых разрешены запросы. Если оставить пусто, разрешён только тот же домен.

## 5. Ошибки → что увидит пользователь

Любая ошибка: показывается понятное сообщение на языке сайта, затем текст читает голос браузера. Сайт не ломается.

| Ситуация | Сообщение |
|---|---|
| Кончились кредиты ElevenLabs | «Кредиты ElevenLabs закончились — читаю голосом браузера» |
| Сработал дневной лимит | «Дневной лимит озвучки исчерпан — …» |
| Слишком часто | «Слишком много запросов, подождите минуту — …» |
| ElevenLabs перегружен (429/5xx) | сервер сам повторяет запрос 1 раз; если не помогло — «Сервис озвучки сейчас занят — …» |
| Нет сети / сервер недоступен / 90 с без ответа | «Нет связи с сервером озвучки — …» / «Сервер озвучки не ответил вовремя — …» |
| На сервере нет ключа | «Озвучка на сервере не настроена — …» |

Подробности ошибок пишутся только в лог сервера (`[tts] …`), в браузер они не передаются.

## 6. Телефоны (iOS Safari, Android Chrome)

- Звук «разблокируется» прямо в момент нажатия кнопки 🔊: на общем `<audio playsinline>` проигрывается беззвучный mp3. После этого телефон разрешает включить готовое аудио, даже если оно пришло через несколько секунд.
- Один общий аудиоэлемент. Старые `blob:` URL освобождаются, чтобы не расходовать память.
- Если пользователь остановил озвучку, незаконченный запрос отменяется.
- `server.js` поддерживает HTTP Range: без него Safari плохо проигрывает mp3 и видео.

Проверено в Chromium с эмуляцией iPhone 13 и Pixel 7 и со строгой политикой автозапуска. **На настоящих телефонах ещё не проверено.**

## 7. Запуск

### Vercel (рекомендуется)

1. Импортируйте репозиторий в Vercel. Framework: *Other*, сборки нет.
2. Откройте Settings → Environment Variables и добавьте `ELEVENLABS_API_KEY` (Production + Preview). При желании добавьте переменные из `.env.example`.
3. Нажмите Deploy. Сайт откроется по адресу `https://<проект>.vercel.app`, озвучка будет на `/api/tts`.
4. Музыка: положите mp3 в папку `music/` в репозитории.

### Локально, Render, Railway или VPS (Node 18.17+)

```bash
cp .env.example .env      # вписать ELEVENLABS_API_KEY в .env (файл не попадает в git)
node server.js            # http://localhost:8000
```

На Render и Railway ключ задаётся в переменных окружения сервиса, команда запуска — `node server.js`. Там же включите `TRUST_PROXY=on`.

Проверка: откройте `/api/tts` — там должно быть `"ok":true`. В ⚙ Настройках появится строка «✦ Живые голоса подключены через сервер · eleven_v4».
